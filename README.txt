# セロトニン習慣トレーナー（Android向けWebアプリ）

## できること
- 8項目の毎日チェックと達成率計算
- 気分・活力・感想の保存
- 直近30日間の記録と達成率グラフ
- JSON形式のバックアップ／復元
- ホーム画面追加に対応するPWA構成、簡易オフライン対応

## 大切な注意
このアプリはセロトニン量を測定したり、増加を保証したりするものではありません。生活習慣を記録するセルフケア用ツールです。
胸部大動脈瘤などがある場合、運動は主治医の指示を優先してください。

## Androidのホーム画面に追加するまで
このZIPをそのまま開くだけでは、インストール可能なWebアプリにはなりません。PWAとして使うにはHTTPSで公開する必要があります。

### GitHub Pagesで公開する例
1. GitHubにログインし、新しいPublicリポジトリを作成（例: serotonin-habit）。
2. ZIPを解凍し、`index.html`、`manifest.webmanifest`、`sw.js` をリポジトリの最上位にアップロード。
3. リポジトリの Settings → Pages を開く。
4. Build and deployment で Deploy from a branch、Branch は main、Folder は /(root) を選び Save。
5. 公開完了後に表示される `https://...github.io/serotonin-habit/` のURLをAndroidのChromeで開く。
6. Chrome右上の ⋮ →「ホーム画面に追加」または「アプリをインストール」を選ぶ（表示は端末により異なります）。

## データについて
記録は端末のブラウザ内（localStorage）に保存されます。同じ端末・同じブラウザで利用してください。ブラウザデータ削除や端末変更に備えて、アプリ内の「記録をバックアップ」を定期的に使ってください。複数端末間の同期はありません。
